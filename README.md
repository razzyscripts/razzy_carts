# 🛒 Razzy Carts

Razzy Carts is a modern e-commerce website project created with **HTML, CSS, and JavaScript**.

The website is designed as a shopping platform where users can browse products, view categories, manage a cart, and go through a checkout process.

### 💳 Payment / Checkout

The Payment page allows users to review their cart and complete the checkout process.

It includes:

- Payment methods
- Card payment section
- Billing information
- Products from the shopping cart
- Subtotal
- Delivery fee
- Discount
- Final total

The checkout page automatically updates based on the products in the user's cart using JavaScript.
