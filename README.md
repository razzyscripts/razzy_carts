# 🛒 Razzy Carts

Welcome to **Razzy Carts**, a modern e-commerce website project designed to showcase products in a clean and user-friendly shopping interface.

## ✨ Features

- 🏠 Home page with a promotional hero slider
- 🛍️ Multiple product categories
- ⭐ Featured products
- 🔎 Search bar
- 📱 Modern and responsive design
- 📰 News and articles section
- ℹ️ About Us page
- 🎨 Custom Razzy Carts branding
- 🧭 Navigation between different pages

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **JavaScript** — Interactive features and functionality
